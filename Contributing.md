contributing_content = """# Contributing to BOSC Community Library

First off, thank you for considering contributing to the BOSC Community Library! It's people like you that make this a great resource.

🛠 Technical Workflow
1. Repository Setup
Fork the project.

Clone your fork: git clone https://github.com/nambatya-joan256/BOSC-Community-Library.git.

Create a Feature Branch: git checkout -b feature/AmazingFeature.

2. Commit Message Standards
We follow Conventional Commits to maintain a clean and readable history. Please format your messages as follows:

feat: A new feature.

fix: A bug fix.

docs: Documentation changes only.

refactor: Code changes that neither fix a bug nor add a feature.

chore: Updating build tasks, package manager configs, etc.

3. Submission Process
Ensure your code follows the existing style of the project.

If adding code, please add corresponding tests in the /tests folder.

Push to the branch: git push origin feature/AmazingFeature.

Open a Pull Request using our standard template.
